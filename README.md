# NEU ACM CF

东北大学 ACM 队 Codeforces 训练统计页，使用 Vue 3 + TypeScript + Vite 构建。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目已配置 GitHub Pages 子路径部署，目标地址为：

`https://stonexieac.github.io/NEU-ACM-CF/`

## 发布到 GitHub Pages

1. 把当前仓库推送到 GitHub 仓库 `stonexieac/NEU-ACM-CF`。
2. 打开仓库设置中的 `Settings -> Pages`。
3. 在 `Build and deployment` 中把 `Source` 设为 `GitHub Actions`。
4. 保证默认分支为 `main`，之后每次推送到 `main` 都会自动发布。
